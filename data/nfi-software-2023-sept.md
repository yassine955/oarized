### During my recent internship, I worked on a project related to Toucan.

Toucan is an existing system that needed improvement, particularly in terms of modularity and expandability. This system is used to monitor WhatsApp updates and detect changes in the database, which are then recorded.

It is important to check whether there are differences in the database, especially if those changes could cause issues for Hansken, potentially preventing digital investigators from carrying out their work.

My goal was to expand this existing application so that it supports multiple applications. This would allow the Hansken team to test more apps and make the Toucan codebase more organized for future additions.

Toucan is a critical tool for the team, as it is part of Hansken. As mentioned earlier, forensic investigators continuously examine mobile devices, reading messages, photos, and other data for specific investigations. It is crucial that this data can be retrieved across different applications. If it cannot be retrieved (due to potential database changes), forensic investigators need to be aware of this in time. Otherwise, there's a risk that evidence might go undetected, allowing suspects to walk free.

The main tasks were to improve the Toucan codebase. The code needed to be written in a structured manner. Additionally, I conducted research into the existing codebase to analyze areas that could be improved or optimized. A new user interface was also explored, as the current interface lacked clarity. In the future, more apps will be added, so a clear and scalable interface is essential.

All of this will result in an improved version of Toucan — a system that performs faster, supports multiple applications, includes a new user interface, and features revised documentation due to the newly structured codebase. The goal is for Toucan to function more efficiently, making it easier for developers to implement changes in Hansken, thus enabling forensic investigators to continue their work without disruption.
